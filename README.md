# Monochrome Ledger

Полнофункциональный трекер личных финансов с авторизацией, поддержкой нескольких валют, интернационализацией и экспортом данных.

## О проекте

Monochrome Ledger — это приложение для учёта личных доходов и расходов. Позволяет отслеживать финансы, анализировать траты и управлять данными.

Основные функции:
- Добавление, редактирование и удаление транзакций
- Фильтрация по дате, категории и поиску
- Экспорт в CSV, PDF и Excel
- Дашборд с ключевыми метриками
- Поддержка нескольких валют с актуальными курсами
- Светлая и тёмная темы
- Русский и английский языки
- Управление профилем пользователя

## Функциональность

### Авторизация
- Регистрация и вход
- JWT-токены с автоматическим выходом при просрочке
- Защищённые маршруты

### Транзакции
- Полный CRUD
- Привязка к пользователю
- Поддержка разных валют

### Дашборд
- Текущий баланс
- Доступные средства
- Изменение за месяц
- Самая дорогая категория

### Фильтрация
- Поиск по описанию
- По категории
- По дате (Сегодня, 7д, 30д, Произвольный диапазон)

### Экспорт
- CSV
- PDF
- Excel

### Настройки
- Валюта (100+ валют через ExchangeRate-API)
- Тема (Тёмная/Светлая)
- Язык (Русский/Английский)
- Формат даты
- Начало недели
- Количество транзакций на странице
- Уведомления (позиция, анимация, вкл/выкл)

### Профиль
- Изменение имени пользователя
- Изменение email (с подтверждением пароля)
- Смена пароля

## Архитектура

### Структура фронтенда

src/
- UI/          Компоненты (отрисовка)
- BLL/         Бизнес-логика (кастомные хуки)
- DAL/         Запросы к API
- store/       Zustand (глобальное состояние)
- assets/      Статические файлы
- locales/     Переводы (i18n)
- types/       TypeScript типы

### Структура бекенда

backend/
- src/
  - controllers/   Обработчики запросов
  - routes/        API-эндпоинты
  - middleware/    Проверка JWT
  - db/            Подключение к БД
  - utils/         Вспомогательные функции
- prisma/          Схема и миграции
